# Controle de Estoque em Java

Projeto desenvolvido para praticar conceitos básicos de programação em Java.

## Objetivo

Criar um sistema simples de controle de estoque, permitindo trabalhar com informações como:

- Nome do produto
- Preço
- Quantidade em estoque
- Entrada e saída de produtos

## Conceitos praticados

- Classes e objetos
- Atributos e métodos
- Encapsulamento
- Construtores
- Estruturas condicionais
- Operações básicas em Java

## Tecnologias utilizadas

- Java

## Sobre o projeto

Este projeto foi desenvolvido com fins de estudo e prática dos fundamentos da linguagem Java.
